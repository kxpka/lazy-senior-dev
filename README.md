# lazy-senior-dev

Agent skill: write code like a lazy senior developer. Stdlib and existing dependencies first, YAGNI, KISS, no boilerplate.

## Install

Claude Code plugin:

```
/plugin marketplace add kxpka/lazy-senior-dev
/plugin install lazy-senior-dev@lazy-senior-dev
```

Or copy the skill by hand:

```
git clone https://github.com/kxpka/lazy-senior-dev
cp -r lazy-senior-dev/skills/lazy-senior-dev ~/.claude/skills/
```

Skill file: [skills/lazy-senior-dev/SKILL.md](skills/lazy-senior-dev/SKILL.md)
